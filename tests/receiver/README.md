点击输入框后以系统热键呼出PoC，再选择文本、单图或队列。页面监听浏览器真实paste事件并记录文件SHA-256、尺寸、解码RGBA SHA-256、透明像素数量、事件顺序；不会模拟或调用PoC粘贴命令。仅有真实事件才增加计数。导出JSON后与fixture清单比较，浏览器转码导致字节不同须单独说明。
