## 已通过的用户实机验收清单（保留复现步骤）

先正常退出旧程序，在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-b2-r2.ps1 -Fixture empty
```

默认独立库为 `evidence/b2-r2/manual-empty`；重启继续使用同一脚本，不清空数据。

1. **外观**：编辑态图片尺寸不变；框外操作栏消失；右下半透明胶囊只显示断链替换与垃圾桶移除；编号、细蓝边和选中对勾正确。
2. **拖动**：参考图半透明跟随，其他图片实时动画让位，松手保留新顺序；效果图不参与。按 Esc 取消拖动，只恢复顺序，不退出整张卡片编辑。
3. **图片操作**：按钮点击不触发拖动；替换作用于指定图片，移除不影响其他案例的共享图片；追加入口和 Ctrl+V 仍可用。
4. **自动草稿**：点击铅笔进入编辑，修改正文，先不要保存。编辑器底部必须从“草稿暂存中”变为“自动保护草稿”。普通卡片“今天 · X 张参考图”不代表有待恢复修改。
5. **异常恢复**：确认自动保护后，在任务管理器结束本次测试程序，重启并打开主库，恢复草稿。文字、图片及顺序应保留；正式旧版不变，手动保存后才更新。无需真实断电。
