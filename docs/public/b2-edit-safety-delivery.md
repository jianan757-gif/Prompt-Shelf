## B2 基础实现

| 能力 | 实现与边界 |
|---|---|
| 自动草稿 | 文本停输 600ms、连续输入约 2s 发起暂存；图片变更立即暂存。后端确认后才显示自动保护状态。未确认落盘的最后输入不承诺异常退出零丢失。 |
| 数据隔离 | 草稿与正式案例分开；新项目、标签只保存在草稿，不污染正式分类。schema 2 为现有表补充必要字段及草稿标签表。 |
| 正式保存 | 沿用 B1 校验及版本检查；正式保存和消费草稿同一事务，失败保留原数据及草稿。 |
| 取消与切换 | 脏编辑在取消、切案、搜索筛选时统一选择保存并继续、继续编辑或放弃修改；失败不执行离开动作。布局与排序保留当前编辑。 |
| 关闭与退出 | 主库按钮、原生关闭和托盘退出经关闭请求握手；编辑未处理不销毁窗口。关闭期间阻止新编辑会话。 |
| 异常恢复 | 启动主库提示未完成草稿，逐份恢复；恢复仅继续编辑。原案例缺失、删除或版本冲突时不自动覆盖，可明确选择作为新草稿继续。 |
| 图片安全 | 沿用 SHA-256 原图共享及独立引用；放弃草稿只清关系，不删除共享原图。未加入文件 GC。 |

关键文件：`poc/src-tauri/src/drafts.rs`、`drafts/tests.rs`、`closing.rs`、`editing.rs`、`cases.rs`、`migrations/002_drafts.sql`；前端 `poc/src/library/useCaseEditor.ts`、`draftSafety.ts`、`EditSafetyDialogs.tsx`、`LibraryManager.tsx`。原 Windows 平台、粘贴队列及 Esc 模块未改写。沿用 V4.11/V5.0 视觉与搜索去蓝色描边要求；新增编辑安全状态、弹窗和图片编辑区已获用户视觉验收。

## Windows 验收入口

从项目根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-b2-r2.ps1 -Fixture empty
```

默认独立库为 `evidence/b2-r2/manual-empty`，重启继续使用同一目录，脚本不会清空已有数据。程序位于 `poc/src-tauri/target-stage-b2-r2/release/`，需 GUI 和 store 两个可执行文件。先正常退出其他版本。

| 操作 | 预期结果 |
|---|---|
| 新建填部分内容、加图，等自动保护提示 | 尚未保存的草稿不出现在快捷面板正式案例中。 |
| 编辑已保存案例后取消、切换案例、搜索或筛选 | 三选弹窗；继续编辑保留内容，放弃恢复正式旧版，保存并继续执行原动作。 |
| 空标题/正文时选择保存并继续 | 中文校验提示，窗口及编辑保留，不执行切换或关闭。 |
| 分别测试主库关闭、Alt+F4、托盘退出 | 未保存时均拦截；继续编辑留窗，成功保存或明确放弃后才关闭。 |
